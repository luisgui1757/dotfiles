## Highlights

- New tools on macOS, Linux and Windows, with SHA-256 archive pins:
  - superfile 1.6.0 (`spf`). `Shift+Q` quits into the folder that you browsed.
  - Atuin 18.24.3. When you select Atuin, `Ctrl+R` opens Atuin. Without
    Atuin, `Ctrl+R` opens fzf. History stays on the machine. Sync uses only
    `127.0.0.1`, and the update check and the AI assistant are off. Atuin does
    not take Up, Down or `?`.
- Rose Pine in each tool. fzf, LazyGit, Atuin and superfile use the official
  Rose Pine themes. Local fixes replace the theme colors that are not Rose Pine
  colors. The gh-dash colors transpose the official Catppuccin port. 128
  superfile icon colors and 6 gh-dash colors are in the program code, and they
  do not change.
- gh-dash: `M` merges with `gh pr merge --admin`. It works only for a ruleset
  bypass actor. `m` keeps the normal merge.
- Mac keys:
  - Ghostty: ``Ctrl+Option+` `` toggles the quick terminal. `Option+Left` and
    `Option+Right` move by word on Linux too.
  - zsh: the Mac line editing keys work in both vi keymaps. `KEYTIMEOUT` is
    50 ms.
  - Herdr: `prefix+|` splits and `prefix+d` detaches, as in tmux.
  - Linux (xremap): each Mac key does what it does on a Mac, and nothing else.
    Right Option is Option. GNOME keys that a Mac does not have do nothing. A
    Mac habit no longer locks the screen, closes a window or shows a text
    console.
- Over SSH, Neovim copies to the local clipboard through OSC 52 when no
  clipboard tool works.
- Sentinel moves to commit `1bb66d5`. The `core` skills add `cleanup`,
  `no-comments`, `technical-writing`, `tldr` and `why`.
- Neovim 0.12.6, Starship 1.27.0 and tree-sitter 0.27.1.
- `main` no longer has `migrate.sh` and `migrate.ps1`. The `v1.0.1` tag keeps
  them.

## Compatibility and upgrade

The supported platforms do not change: Apple Silicon macOS, Ubuntu and Debian
on amd64 or arm64, and native Windows amd64. WSL uses the Ubuntu and Debian
items.

To move from v1.0.1:

1. With the checkout that you have, finish or abandon each interrupted
   operation.
2. Update the checkout to `v1.1.0`.
3. Open setup and choose Update tools. Update installs the new pins and the new
   Sentinel commit.
4. To add superfile or Atuin, choose Choose tools and select them.

To move from v0.4.x:

1. Check out `v1.0.1` and run `./migrate.sh` or `.\migrate.ps1`. Finish all
   phases.
2. Update the checkout to `v1.1.0`. Open setup and choose Update tools.

A state that only v1.0.0 or a pre-release build wrote stops with
`unknown resource` before any change. Update that checkout to `v1.0.1` and
choose Update tools first. Then update to `v1.1.0`.
