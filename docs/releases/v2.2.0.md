# v2.2.0 — T3 Code settings and the Rosé Pine Moon theme

## Highlights

- **T3 Code settings**: the **T3 Code** and **T3 Code server** selections now
  set these fields in `~/.t3/userdata/settings.json`:
  - Worktrees: delete merged worktrees and the worktrees of deleted threads,
    and use semantic branch names.
  - Threads: start new threads in a new worktree, do not auto-settle merged or
    inactive threads, and resume after usage limits.
  - Source control: squash and merge, and remove agent credits when merging.
  - Compact idle threads on return, and disable provider update checks.

  The README lists each field and value. Setup uses `~/.t3` also when
  `T3CODE_HOME` names another folder.
- **Rosé Pine Moon theme**: setup writes
  `~/.t3/userdata/themes/rose-pine-moon.json` and sets `defaultTheme` to it.
  Each T3 client changes to the theme one time. T3 keeps a theme that you
  select later. The theme comes from the `mvllow.rose-pine` 2.15.2 extension,
  under the MIT license.

Setup owns only these fields. Models, favorites, providers, credentials and all
other T3 settings stay personal. Removal restores the values that were there
before.

## Compatibility and upgrade

The supported platforms do not change: Apple Silicon macOS, Ubuntu and Debian
on amd64 or arm64, and native Windows amd64. WSL uses the Ubuntu and Debian
items. The steps are the same on each platform. Use `setup.sh` on macOS and
Linux, and `setup.ps1` on Windows.

This release reads the same installer states as v2.0.0: the states of v1.2.0
and later.

To move from v1.2.0, v2.0.0 or v2.1.0:

1. With the checkout that you have, finish or abandon each interrupted
   operation.
2. If T3 runs, stop it.
3. Update the checkout to `v2.2.0`.
4. Open setup and choose **Update tools**. Run **Check**, and fix each problem
   that it reports.

When `~/.t3/userdata/settings.json` already has one of the owned fields,
**Update tools** shows `integration.t3-code` for adoption. It does not show it
when the file already has each owned field with the dotfiles value. Adopt it to
apply the settings. Until you adopt it, setup does not change the file.

To move from an older release, update to `v1.2.0` first. Follow
[From a release before v1.2.0](../UPGRADING.md#from-a-release-before-v120).

The settings and the theme passed an end-to-end test on Linux amd64, with T3
v0.1.7 in headless Chromium. The test covered a fresh apply, a T3 rewrite of its
own file, adoption, and removal. The installer tests of the pull request passed
on the hosted macOS, Linux amd64 and arm64, and Windows runners. We did not
test the T3 user interface on macOS or Windows. We did not test an update of an
installed machine from v2.1.0 to this release.
