## Highlights

- POSIX Nix prerequisite reconciliation now safely merges `nix-command` and
  `flakes` into an existing user `nix.conf`, preserves unrelated settings and
  comments, and removes its same-directory stage on every trapped failure.
- Neovim's pinned plugin checkout can recover an abandoned cache lock only
  when the recorded owner PID is proven dead. Live, malformed, ownerless, or
  otherwise unprovable locks remain fail-closed with an actionable path.
- Chezmoi diff, status, and dry-run rendering no longer creates the zsh plugin
  parent tree or publication locks when the pinned plugins are absent.
- The reviewed Nix digest ledger is shape-checked against the implementation,
  and the POSIX uninstall backup-order oracle now runs in required Linux and
  macOS CI with a policy guard against future migration-test omissions.

## Compatibility and upgrade

This is a backward-compatible patch release. It repairs recovery, preview, and
verification paths without changing managed target locations, package
ownership, or persisted application data shapes.

Do not update an older checkout in place. Clone the exact annotated `v0.4.3`
tag beside the checkout that currently owns live config, then run:

```bash
./setup.sh --all
```

```powershell
.\setup.ps1 -All
```

Existing v0.2.0, v0.3.0, v0.4.0, v0.4.1, and v0.4.2 installations use
ordinary setup reconciliation from the new checkout. The same entrypoints
support a direct side-by-side v0.1.0 migration through the versioned
frozen-source transaction. Keep the prior checkout and any printed recovery
directory until setup completes and the applications you use have been
checked. An unfinished earlier recovery must be accepted or rolled back from
its retained exact release checkout first; v0.4.3 setup refuses to bypass it.

## Release identity

The POSIX prerequisite helper and both v0.1.0 migrators require the tag name

object, peeled commit, clean HEAD, and matching official-remote identities. The
explicit `--allow-unreleased` POSIX field-test lane may instead accept a clean
current official branch head; that lane is not migration authority.
